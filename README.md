# 🩺 Medical Report Analyzer using Generative AI

An AI-powered medical report analysis system that uses Generative AI to analyze uploaded medical reports and generate intelligent summaries, insights, and simplified explanations for better understanding.

This project helps users quickly interpret medical documents using AI-based text analysis and natural language processing techniques.

---

## 🚀 Features

* 📄 Upload medical reports
* 🤖 AI-generated medical report analysis
* 🧠 Intelligent text summarization
* 📊 Simplified health insights
* ⚡ Fast and interactive interface
* 🌐 User-friendly dashboard

---

## 🛠️ Technologies Used

* Python
* Generative AI
* NLP (Natural Language Processing)
* Flask
* HTML/CSS/JavaScript
